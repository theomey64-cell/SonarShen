SONOR V6 — Arcade Edition

Installation : npm install puis npm start.
Render : Web Service Node, build npm install, start npm start.

Nouveautés : accueil arcade inspiré des jeux de soirée, sélection de 7 avatars, avatars visibles dans le salon, design responsive.

Les avatars sont des illustrations caricaturales. Les vidéos YouTube intégrées restent soumises aux restrictions YouTube et du navigateur. Les salons sont stockés en mémoire et peuvent être perdus si Render redémarre.
